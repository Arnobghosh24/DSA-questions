<h2><a href="https://www.geeksforgeeks.org/problems/minimum-absloute-difference-between-adjacent-elements-in-a-circular-array-1587115620/1">Minimum adjacent difference in a circular array</a></h2><h3>Difficulty Level: Easy</h3><hr><p><span style="font-size: 18px;">Given an array <strong>arr[]</strong> where integers arranged in a <strong>circular</strong> fashion. Return the minimum absolute difference between adjacent elements.</span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>arr[] = [8, -8, 9, -9, 10, -11, 12]
<strong>Output: </strong>4<strong>
Explanation: </strong>Adjacent absolute differences are 16, 17, 18, 19, 21, 23, and 4 (between first and last). The minimum is 4.</span></pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong>arr[] = [10, -3, -4, 7, 6, 5, -4, -1]
<strong>Output: </strong>1<strong>
Explanation: </strong>Adjacent absolute differences are 13, 1, 11, 1, 1, 9, 3, and 11 (between first and last). The minimum is 1.</span>
</pre>
<p><span style="font-size: 18px;"><strong>Constraint:</strong><br>2 ≤ arr.size() ≤ 10<sup>6</sup><br>-10<sup>6</sup> ≤ arr[i] ≤ 10<sup>6</sup></span></p>
